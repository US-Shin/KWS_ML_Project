# 서비스 화면 캡처

현재 Hugging Face Spaces에 로그인/배포하지 못했고, 이 PC에는 브라우저에서 사용할 마이크 입력 장치도 노출되지 않아 서비스 화면 캡처 3장을 아직 만들지 않았습니다. 제출 전 실제 배포 페이지에서 아래 파일을 캡처해 이 폴더에 추가하세요.

1. `01_demo_home.png` - 서비스 첫 화면과 지원 키워드 안내
2. `02_prediction.png` - 마이크 또는 음성 파일 입력 후 예측 결과
3. `03_rejection.png` - 무음 또는 낮은 신뢰도 입력의 거절 안내

평가 시연 결과 그림은 프로젝트의 `results/` 폴더에 있습니다. 결과 그래프를 서비스 화면 캡처로 대체하지 마세요.
